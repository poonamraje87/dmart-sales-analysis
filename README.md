## 📌 Project Overview
This project showcases an interactive **DMart Sales Analysis Dashboard** created in **Microsoft Excel**. It transforms raw retail sales data into meaningful business insights using Pivot Tables, Pivot Charts, KPI cards, slicers, and Excel formulas.

## 🎯 Business Problem
Retail businesses need an easy way to monitor sales performance, profitability, category trends, regional performance, and payment preferences. This dashboard provides decision-makers with a single interactive view for faster business decisions.

## 🚀 Dashboard Features
- Total Sales, Profit and Net Sales KPIs
- Units Sold, Total Orders and Average Order Value
- Region-wise Sales Analysis
- Year-wise Sales Comparison
- Category-wise Sales
- Top 3 Categories
- Payment Segment Distribution
- Interactive Category and Year Slicers

## 📈 Key Insights
- Electronics generated the highest category sales.
- Sales remained consistent across both years with monthly comparisons.
- South region recorded strong performance.
- Card, Cash, and UPI payment methods contributed almost equally.
